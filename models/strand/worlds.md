## what a world is

- further than basics: the chapters as a framework, and a world as one
  crystallization/realization of it, tailored to a use
- what a world can do: keep, redefine, leave out or add to anything in the
  chapters, even what counts as a strand
- why it matters: a world communicates its semantics precisely, with as little
  room as possible for miscommunication/misrepresentation

## the defaults the running text takes

each chapter defines its choices; this is where the defaults are gathered, one
row per choice:

| choice | default | alternatives |
| --- | --- | --- |
| perspective on the states | asymmetric | symmetric |
| reading | presence and absence: true and null | a spacer, a selection, truth values, others |
| type | unidirectional fluid | abstract, bidirectional fluid, solid only |
| how a type changes | only through a function named for it | through context, not at all, or freely |
| identity | identical | up to start, up to direction, up to type, matches |
| distance | the + way round | the − way, the shortest way |
| framing, when strands are set side by side | as written | any frame |
| commitment | one-way | melting back, with bidirectional fluid |

## reading the chapters from another world

- in an abstract world, read "fluid" as "abstract", and `/…/` as `|…|`: abstract
  and unidirectional fluid allow exactly the same moves
- other translations still to find, such as how the running text reads in a
  symmetric world

## sketches of worlds

a few worlds, to show the choices working together:

- **a rhythm world**: circular, asymmetric, spacers across time
- **a logic world**: symmetric, read as truth values
- **an abstract world**: no concrete types at all
- **a wider world**: one that changes what a strand is, such as letting it
  cross itself (an idea kept in `rough/crossings.md`)
